A400429
Irregular triangle read by rows: T(n,k) is the number of semi-meanders with n crossings and winding number 2*(k-1) + (n mod 2), for n >= 2, 1 <= k <= floor(n/2).

COMMENTS
A semi-meander is a semi-infinite, self-avoiding, directed curve that crosses a line one or more times.
The winding number of a semi-meander is the hypothetical minimum number of self-crossings that would be created if a ray were to start at the source of the semi-infinite directed curve and extend to infinity without crossing the line.
A semi-meander that crosses a line n times, where n is an even number, has an even winding number, 0,2,...,n-2 correspond to k = 1,2,...,floor(n/2). Similarly, if n is odd, then it has an odd winding number, 1,3,...,n-2 correspond to k = 1,2,...,floor(n/2).
Equivalent to a closed curve (a loop) transversely crossing a ray, considered up to continuous deformation fixing the ray, with a winding number equal to the number of crossings that would be created if the fixed end of the ray were extended to form a line.
Analogized to a river (a semi-meander, meander, or loop) crossing a road (a ray, line, or line segment).
Equivalent to a line with vertices, 1,...,2*n, and each vertex, i, joined by an arch below the line to vertex 2*n+1-i for 1 <= i <= n. T(n,k) counts loops that are the union of noncrossing perfect matchings of lower arches with 2*(k-1) + (n mod 2) upper arches that join a vertex <= n to a vertex > n.
Equivalent to a strip of n stamps, folded such that the first stamp is in the first position, also described as leaf 1 on top or as stamp 1 on the outside.
The number of k values in row n equals floor(n/2).

FORMULA
T(n,1) = A005315(ceiling(n/2)).
T(2*n,2) = A005315(n+1) - 2*A005316(2*n), for n >= 2.
Sum_{k=1..floor(n/2)} T(n,k) = A000682(n).
Sum_{k=1..floor(n/2)} T(n,k) * n = A000136(n).
Let D_j(n) = T(n,floor(n/2)-j+1) denote the j-th diagonal, for 1 <= j <= floor(n/2).
D_1(n) = 2 - 0^(n-2).
D_2(n) = A400631(n) = (n^2 + 2*n + n mod 2 - 20)/2, for n >= 4.
D_3(n) = A400632(n) = [13*n^4 + 24*n^3 - 284*n^2 - 4560*n + 17920 + (n MOD 2)*(18*n^2 - 72*n + 189) - 0^(n MOD 3)*64]/288, for n >= 6.
D_4(n) = A400633(n).
A005316(n) = T(n,1) + (1 - n mod 2) * [T(n,2) - T(n-1,2)]/2, for n >= 5.
A076876(n) = [T(n,3) - T(n,2) + T(n+1,1) - 2 * T(n+1,2) + T(n+2,2)]/2, for even n >= 6.
A006661(n+4) = [T(n,3) - 2 * T(n,2) + 2 * T(n+1,1) - 2 * T(n+1,2) + T(n+2,2)]/2, for even n >= 6.
A077054(n) = [T(2*n+1,1) - T(2*n,2)]/2, for n >= 2.
A077460(n) = [T(2*n,1) + T(n+1,1) - T(n,2)]/4, for even n >= 2.
A077460(n) = [T(2*n,1) + T(n, 1) + Sum_{k=1..floor(n/2)} T(n,k)]/4, for odd n >= 3.
T(n,k) = a(i), where i = 1 + k + floor((n-1)^2/4).
Conversely, a(i) = T(n,k), where n = ceiling(2*sqrt(i-1)) and k = i - 1 - floor((n-1)^2/4).
